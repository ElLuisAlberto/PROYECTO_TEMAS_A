# Evidencia

Esta carpeta contendrá evidencia de cada hito y ensayo.

~~~
screenshots/  estado de interfaz, simulación y métricas
videos/       demostraciones y respaldo de presentación
logs/         registros de servidor, ROS y red
figures/      gráficas y tablas exportadas
~~~

Usar nombres trazables, por ejemplo:

~~~
2026-11-01_run-003_T08_N2_liberacion_operador-a.mp4
2026-11-01_run-003_metricas.csv
~~~

Cada archivo debe aparecer referenciado desde su hoja de ensayo correspondiente.
